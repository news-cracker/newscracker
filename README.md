# 뉴스크래커 (NewsCracker) 다운로드 페이지

뉴스크래커 앱의 iOS·Android 다운로드 링크를 모은 모바일 랜딩 페이지입니다.
`linktr.ee/newscracker`를 대체하기 위해 만든 정적 페이지로, 빌드 과정 없이 `index.html` 하나로 동작합니다.

- iOS: App Store (id6746927652)
- Android: Google Play (`com.newscracker.news_app`)
- 문의: news0cracker0@gmail.com

## 구성

| 파일 | 용도 |
| --- | --- |
| `index.html` | 페이지 본체 (인라인 CSS, 외부 CDN·스크립트 없음) |
| `icon-180.png` | 파비콘 / 애플 터치 아이콘 / 헤더 아이콘 |
| `icon-512.png` | 공유 미리보기(og:image)용 |

## 배포

GitHub Pages(main 브랜치 `/`)로 배포합니다. 별도 빌드 없이 저장소 루트를 그대로 올리면 됩니다.
